01 · RESEARCH CONTRACT

训练的不是答案链，
而是可复用的世界状态。

测试组合的每个原子操作都必须在训练中出现；完整 signature 必须没有出现，并且 scene 与 family 严格隔离。

CAUSAL AXIS

Atoms(test) ⊆ Atoms(train)
Signature(test) ∉ Signature(train)

只有同时满足这两个条件，才是在测组合，而不是测新技能或模板迁移。

OBSERVE

Question-after-evidence

所有图像 token 都在问题 token 之前；显式状态是独立 auxiliary export，不伪装成主 SFT 输入。

READ

Typed I/O closure

Relation 必须消费实体与 frame；Perspective 必须消费 belief 与 target view。

VERIFY

Independent execution

certificate 来自几何规则，不由模型用文字自我确认。
