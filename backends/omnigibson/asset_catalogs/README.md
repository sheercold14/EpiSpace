# External asset catalog

`behavior_static_m1.lock.json` is the authoritative asset list for the first
OmniGibson static-camera episode. Paths are relative to the repository root.

The manifest deliberately does not contain or redistribute external assets or
the BEHAVIOR decryption key. Verify each archive's exact byte size and ZIP CRC
after transfer. Install `omnigibson.key` only through the official utility on the
destination machine after accepting the BEHAVIOR Data Bundle agreement.
