01 · FIRST PRINCIPLES

Accuracy 不是心智模型。
模型性必须能被测量。

五条认知性质同时定义数据结构、训练奖励与评测协议。右侧状态只描述当前 M1 artifact，不外推训练结果。

P1IN ARTIFACT

持久性 · Persistence

状态跨视图与跨查询保留，不为每一道题重新解释世界。

可测量：state delta、state-only sufficiency
P2PROTOCOL NEXT

路径无关 · Path independence

同一组证据以不同合法顺序摄取，最终状态与答案应收敛。

可测量：shuffle state distance / Δaccuracy
P3IN ARTIFACT

视角等变 · Equivariance

ego 与 allo 查询通过显式 frame transform 闭合，而非依赖隐式方向词。

可测量：canonical↔ego cycle error
P4IN ARTIFACT

组合闭合 · Closure

相邻变换的复合必须与跨视角直接估计一致；答案能从 state 再执行得到。

可测量：pose closure、state↔answer agreement
P5SCHEMA READY

知所不知 · Epistemic awareness

能力缺口、欠定证据和低 margin 必须显式 rejected / unknown。

可测量：selective risk、abstention calibration

05 · SFT OBJECTIVE

训练的目标不是复述 trace，
而是学会更新并执行状态。

同一 episode 内先摄取 M 个 view，监督每步状态变化；再从最终/中间 state 批量读取 K 个问题。Oracle 通道只产监督，绝不作为模型输入。
