# 剧本设计:自运动更新 + 路径积分(完整版,待 review)

> 定位:能力框架(`scriptgen能力框架_v1.md`)里基元C与组合一的完整
> 剧本设计。这两个能力共用同一批录像,所以合写一份。
> 状态:v1 骨架已实现并验证;本文补全子型设计,含待拍板决策(§8)。

## 1. 这一簇测什么

一条录像,四道题,考的是一条流水线的不同截面:

- **路径积分**(基元C):把帧间画面变化累加成"我自己怎么动的"。
  只问自我,不问物体。
- **自运动更新**(组合一):在积分之上,再把"我怎么动的"反过来作用到
  记住的物体位置上,得出"它现在在我哪边"。等于 读出 + 积分 + 变换。

两道主打题之外配两道辅助题(指回起点、画面侧),四道题构成诊断梯:
哪一级开始错,病灶就在哪一环。

## 2. 录像怎么拍:五种轨迹子型

所有子型共享的底线(已实现,std.v4):不穿家具不穿墙(0.3 m 人体
半径)、逐帧可追踪(转向≤40°/帧、位移≤1.2 m/帧)、目标经历
看见→过渡→彻底消失三段、答案离判界有裕度。

| 子型 | 拍法 | 单独考什么 | 状态 |
|---|---|---|---|
| T1 标准走动 | 看见目标→边走边转离开→终点环顾提问 | 平移+旋转混合更新(默认) | **已实现** |
| T2 纯旋转 | 站定看见目标→原地转身超过目标出视野→提问 | 只考旋转更新,平移为零 | 待做,新拍法 stand_and_turn |
| T3 纯平移 | 看见目标在侧前方→直线走过去不转头→提问 | 只考平移更新(直行也会改变目标相对方位) | 待做,新拍法 walk_straight_past |
| T4 多段转向 | 同 T1,但总转角拆成 2–3 次转弯,中间直行 | 多段运动的串联累计 | 待做,T1 参数化 |
| T5 遮挡消失 | 目标还在视野锥内,但被高家具/墙挡住 | "看不见"≠"在身后";补出 front 类答案 | 待做,要换多房间场景 |

T2/T3 的取舍依据是 Rieser(1989)的人类结果:旋转后的更新费力,
平移后的更新接近自动。模型是否有同样的不对称,只有拆开拍才测得到。

T5 的前提改动:现在"什么东西挡视线"是按标签白名单(墙、柱)判的,
改成按高度判——凡是顶面高过相机(1.5 m)的障碍都算遮挡物。单间卧室
里够高的家具只有床沿(1.61 m),所以 T5 主力用多房间场景,靠墙来挡,
场景从现有 sweeps 数据里选。

配套修一个已知毛病:**答案偏科**。实测 80 条计划里"左"53 条、
"右"9 条,病根是拍法转弯偏一个方向。修法:转弯方向抛硬币 +
终点环顾方向的概率校准。验收线(待拍板,见 §8):左、右各≥25%,
后≥15%;T5 上线后 front 也进分布。

## 3. 四道题的完整定义

每道题:金标怎么算、什么条件下才成题、四种变体下金标该怎么变。
"变体"指对已渲染帧序列的四种手术:打乱顺序(gone 段)、删光目击帧、
删冗余帧(逐帧验证)、原地停顿(重复一帧)。所有金标由编译器重算,
预期只做核对,不符即拒绝出厂。

### 3.1 方向题(组合一主打,已实现)

- 题面:"以最后一帧你的位置和朝向为准,{target}现在在你的哪个方向?"
  选项 front/left/back/right/无法判断。
- 金标:提问帧位姿 × 目标坐标 → 方位角 → 四扇区;离扇区边界 ≥15°。
- 成题条件:目标看见过、彻底消失 ≥3 帧、累计转角 80–200°、裕度达标。
- 变体预期:打乱→弃答(顺序即证据);删目击→弃答;删冗余→不变;
  停顿→不变。

### 3.2 净转向题(基元C主打,已实现)

- 题面:"这段行走中,你的净转向是向左还是向右?"选项 left/right/无法判断。
- 金标:逐帧偏航增量**带符号**求和(不是绝对值累计,两者是不同的量);
  |净转角| ≥15° 才成题。
- 变体预期:打乱→弃答;删冗余→不变;停顿→不变。没有"删目击"变体
  ——这道题没有目击这回事。
- 待扩展(§8 决策):是否加第二问"净转角超过 90° 了吗",把单轴二分
  变成方向×幅度四分,给角度曲线多一个刻度。

### 3.3 指回起点题(探针:积分+变换、免读出,已实现)

- 题面:"你出发时所在的位置,现在在你的哪个方向?"选项同方向题。
- 金标:提问帧位姿 × 第 0 帧相机位置 → 四扇区。
- 成题条件:起点距终点 ≥1 m(纯旋转轨迹自动不出此题,合理)、
  扇区裕度 ≥15°。实测三条现有录像只有一条合格,属正常挑剔。
- 变体预期:同净转向。

### 3.4 画面侧题(操纵检查,已实现)

- 题面:"最后一次看到{target}时,它位于你画面的左半边还是右半边?"
  选项 left_half/right_half/无法判断。
- 金标:目击帧(按掩码定,不按几何估计)方位角的符号;离画面中线 ≥15°。
  实测:掩码定出的目击帧是目标滑到画面边缘那一帧,方位角 37–41°,
  三条录像全部合格——不需要为这道题改拍法。
- 变体预期:打乱→**不变**(目击段不动,翻记录就能答);删目击→弃答;
  其余→不变。
- 角色:质检,不计入能力分。这道题挂科的模型,同录像的方向题成绩
  标记"读出污染"剔除。

### 3.5 子型与题的搭配是自动的

不需要手工指定哪种录像出哪些题:成题条件自己会筛。纯旋转轨迹
起点=终点,指回起点题的"≥1 m"条款自动不出;纯平移轨迹净转角≈0,
净转向题的"≥15°"条款自动不出。每条录像上,四道题各自过各自的条款,
过了就出,没过就在清单里记跳过原因。

## 4. 旋钮与标签(评测端分组用)

打包时写进题目包元数据,评测按标签分组画曲线:

- 延迟(消失到提问的帧数):3–5 / 6–9 / 10+;
- 累计转角:80–120° / 120–160° / 160–200°(角度—误差曲线的 x 轴);
- 转向段数:1 / 2 / 3(T4);
- 变换成分:混合 / 纯旋转 / 纯平移(T1/T2/T3);
- 消失方式:出视野 / 被遮挡(T1–T4 / T5)。

## 5. 这一簇能产出的结论

1. **角度—误差曲线**:方向题错误率随转角桶的形状。平滑上升=模拟式
   更新的行为签名;平坦或断崖=查表或分类捷径。
2. **旋转/平移分离**:T2 vs T3 的方向题成绩差,与 Rieser 人类数据
   同构与否。
3. **诊断梯定位**:画面侧对、净转向对、方向题错 → 病灶在"变换"环节;
   净转向就错 → 连积分都没有。逐模型给出病灶分布。
4. **算与翻的判别**:同一打乱手术下,方向/净转向题弃答、画面侧题
   不变——模型行为是否呈现这个分化,直接对应 H0/H2。
5. **遮挡语义**:T5 上目标在正前方但被挡,答 front 才对。把"看不见"
   等同"在身后"的模型在这里现形。
