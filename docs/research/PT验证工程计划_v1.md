# PT 程序化空间认知：验证工程计划 v1

> 假设（可证伪）：在真值环境下用人类式程序（循迹/联想/视角转换）做过程监督，
> 模型能把空间问题从"多图理解"转为"状态读写与变换执行"，且无需注入完整 3D。
> 强判据不是 benchmark 总分，而是：步骤级干预一致性 + θ 参数化单调签名。

## 0. 不变量（全阶段强制，违者 fail-closed）

1. 模型可见通道只有 RGB + 自然语言；轨迹文本禁止度量坐标，只许人能说出的内容（方位/序数/粗距离/视角归属/掉头事件）。
2. 每个事实句有 claim 证书且可从 bundle 独立复算；每个事实 >=3 种语言表面 + 语料级 n-gram 去重门。
3. 人类可答门：margin>=0.4m、角度 margin>=20°、OBB 净空、像素>=256；不满足则降级表述或不出题。
4. family/场景/轨迹类型三轴锁 split；episode 臂与 isolated 臂共享 comparison_id 与图像多重集。
5. 每轮带 semantic_signature；留出签名永不入训练 exporter（自动审计）。

## M0 感知地板审计（约 1 周，先于一切训练）

- 探针任务（zero-shot，不训练）：跨视图同一性绑定（同/异实例判断）、深度序数（谁更近）、
  ego-motion 方向判断（两帧间相机左转/右转）。素材由编译器从现有 bundle 免费生成。
- 判定：某能力轴地板 < 60% → 该轴问题不进主实验（防止把"看不见"误判为"不会想"）。
- 产出：`m0_perception_floor.json`（按基座模型 x 能力轴）。

## M1 数据引擎完备（约 2 周，全部在现有编译器上增量）

| 项 | 内容 | 验证用途 |
|---|---|---|
| 镜像轨迹变体 | 逆序视图重编译；掉头方向步骤真值翻转、结论不变 | 步骤级干预一致性（H2 主判据） |
| 中介地标移位对 | 接入 t9 relation-flip 对：联想步骤归属改变 | 同上，第二干预类型 |
| θ 参数化 PT | t3 旋转 sweep 按假想朝向与已见视图的角差分桶 {0,45,90,135,180}°；训练只见 {0,45,90}° | 单调签名 + 外推（H2 副判据） |
| 目标视角预测 | t10 sweep 接入 P 算子轮型 | PT 三级覆盖 |
| 配音全量 | 29+ 场景过配音层（trace<=120 字预算；claim 锚定验证） | 抗模板 |
| 三臂导出 | A 纯答案 / B 真值检查点轨迹 / C 自由 CoT（仅答案过滤） | H1 主对照 |
| 步骤评测集 | 每条 trace 的步骤连同干预兄弟打包为 step-eval 记录 | 过程级 ES 指标 |

规模目标：约 60 个轨迹 bundle（static-m2 29 + t3/t10 精选）、≥1500 轮，PT 类占比 >=35%，
unknown 占比 ~15%，方向配额均衡。测试预留：4 test 场景 + 留出签名 + 轨迹类型轴（t7 全部只进考卷）。

## M2 Zero-shot 基线与难度校准（约 3 天）

- 模型：SenseNova-SI-1.1-InternVL3-8B / 2B、InternVL3-8B 原版、（可选）Qwen3-VL-8B。
- 套件：test 场景对话（episode 模式 + isolated 模式）、步骤评测集、vision-free、删证据变体。
- 校准回路：任一轴 zero-shot >85% → 收紧该轴（margin/跳数/角差）后重编译；<15% → 检查感知地板归因。

## M3 三臂训练（约 1-2 周）

- 基座 SenseNova-SI-8B；LoRA r=16-32，LR ~1e-4，<=3 epoch，50% 通用回放；
  三臂按 comparison_id 对齐 Adam 步数与图像曝光；3 种子。
- collator 契约：`loss_policy.train_on=assistant_only` 驱动 label mask；qwen_multimodal_chat 格式即插 ms-swift/LLaMA-Factory。
- 守门：每 500 步 MMBench 子集 + VSI 子集，通用掉 >1.5pp 即停。

## M4 预注册判定门

| 指标 | 通过线 | 含义 |
|---|---|---|
| B vs A：留出签名准确率 | >=+5pp | 程序轨迹有效（H1） |
| B vs C：同上 | B>C 且 C<=A | 复现"自由 CoT 无效"，衬托真值轨迹 |
| 步骤级干预一致性（镜像/移位对） | >=+10pp vs A 臂 | 执行而非表演（H2 主判据） |
| θ 曲线 | 训练桶单调平滑且外推桶不塌方 | 变换真实性（H2 副判据） |
| family 一致性 / 弃答正确率 | >=+10pp | 证据敏感 |
| 通用 QA | 掉幅 <=1pp | 无灾难遗忘 |

任一 H2 判据不动而分数上涨 → 强假设证伪，公开退守 H1 工程结论；不得以加数据代替机制修正。

## M5 机制探针与外部转移（判定通过后）

- 隐状态线性探针：变换步骤 token 处能否解码"目标在假想朝向下的方位"；注意力回流锚点视图分析。
- 外部转移：MindCube rotation/PT 子集、VSI-Bench relative direction、MMSI 多图子集（全程只考不训）。
- RLVR 阶段按训练流程 v1 启动（certificate 判分 + 一致性奖励 + 步骤级过程奖励可选）。

## 风险与止损

| 风险 | 信号 | 止损 |
|---|---|---|
| 感知地板不足 | M0 某轴 <60% | 该轴退出主张，或换 DINOv2 系基座做副实验 |
| 表演通过步骤评测 | 干预一致性高但 θ 外推塌方 | 以 θ 判据为准，收紧干预多样性 |
| 数据量不足以稳定 LoRA | 三种子方差 > 效应量 | 扩 t-sweep 场景而非复制题目 |
| 配音风格泄漏答案 | C/B 臂 vision-free 异常高 | 配音验证器加盲测回归 |
