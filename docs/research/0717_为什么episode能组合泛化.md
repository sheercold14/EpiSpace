1. 先把病根说准：单轮 QA 的失败是"目标函数不可辨识"

  一条孤立样本 (图像O, 问题q, 短答案y) 的 loss 对下面两种解给同样的分：

  - 贵的解（我们想要的）：S = Write(O) 先把观察整合成场景状态，y = Read(S, q) 再在状态上执行查询——Write 和 Read 是所有题共用的；
  - 便宜的解（模型实际学的）：y = H_q(O, q)——每种题型各学一个从图文模式直达答案的捷径函数，互相不共享任何中间件。

  答案 loss 无法区分这两者（paper 里 principles 一节已把这个不可辨识性形式化）。梯度下降永远选便宜的，于是 SenseNova-SI-8M 堆了 800 万条，得到的是八套独立捷径：每
  种能力单测都不差，可组合推理需要把中间结果从一个算子传给另一个算子——捷径没有中间结果可传。这就是"能力无法组合"的机制根源，也解释了他们 CoT
  反而掉分（内部没有可显式化的中间表征）和数据规模化饱和（继续堆量只是把每条捷径磨得更亮）。

  2. 核心假设（一句话，可证伪）

  ▎ 在事实、图像曝光、优化预算完全配平的前提下，"先观察、后多读 + 反事实家族约束"的监督结构，会使"共享状态的写-读解"成为经济上最优的解；其可观测结果是：未见过的算
  ▎ 子组合（签名留出）上的准确率显著更高，且答案随证据干预正确变化（家族一致性）。

  预注册判据：组合留出题 +5pp、家族一致性 +10pp、通用 QA 掉幅 ≤1pp；三种子、scene-cluster bootstrap。达不到就承认假设错了，改机制而不是加数据——这是它和"我们相信
  episode 有用"的区别。

  4. 对 QA 构造的直接推论（这就是"如何进行 QA"的答案）

  核心假设不是哲学，它逐条规定了出题规则——pilot 数据已经在执行的和必须坚持的：

  1. QA 永远不孤立出现：问题必须成批挂在同一次观察之后（observe-first,
  read-many），且一批内跨能力混布——全是方向题的批次形不成摊销压力，必须记忆+度量+关系+弃答混着来。
  2. 每个事实出生时就带兄弟：出一道题的同时必须能编译出它的证据三元组/参照系对/命题对，族锁同一
  split。编译不出完整家族的事实整族丢弃（fail-closed），不做"单身题"。
  3. 弃答必须可证明：unknown 只能来自"证据集里确实推不出"（删帧后无替代证据），且弃答题必须和同族的可答题捆绑出现——防模型学会"遇难就弃"。
  4. 答案只从几何执行来，语言只做重述；答案分布（左/右/前/后、有/无、known/unknown）在场景簇层面强制均衡，让先验拟合无利可图。
  5. 每道题带签名标签（隐藏通道），训练集必须覆盖全部原子、且经审计不含留出签名——这是组合实验成立的前提。
  6. 同一事实同时导出两臂：episode 臂和 isolated 臂共享 comparison_id、相同事实与图像多重集——A/B 对照不是训完再补的，是 QA 编译器的内建输出。

  一句话收束：SenseNova 的问题不是数据不够多，而是监督结构让捷径成为最优解；我们的 QA
  构造就是把监督结构改成"捷径必死、建图最优"，组合泛化是共享状态的自然产物——而这整件事被设计成一个跑完 pilot 就能证真或证伪的实验。
