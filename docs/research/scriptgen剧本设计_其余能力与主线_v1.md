# 剧本设计:其余能力 + 推进主线(待 review)

> 与《自运动与路径积分》设计文档配套,覆盖能力框架里剩下的四块:
> 参考系变换(基元A)、对应锚定(基元B)、跨视图绑定(组合二)、
> 存在题(元能力)。这四块成熟度低于自运动簇,写到"能评审方向"的
> 粒度,不到"能直接开工"的粒度;每节末尾列待定项。
> §5 是推进主线:先把整条 loop 跑起来,再逐个补剧本。

## 1. 参考系变换(基元A)

**拍什么。** 原地环视:相机站定,转一圈把周围看清,目标物和两个
参照物(比如门、床)都清楚入过画。没有任何东西需要记——所有证据
都在画面里,这是刻意的:这个剧本只考"换算",不考记忆。

**问什么。**

- 主打(深档):"如果你站在门口、面向床,{target}在你的哪个方向?"
  金标:把想象站位(门的位置)和想象朝向(朝向床)代入几何,算目标
  方位角,离散四扇区,裕度 15°。这个位姿从没拍过,答案必须算。
- 副题(浅档):"从门口能不能看见{target}?"金标:从门的位置做视线
  判断;模拟器可以真的把相机放过去渲染一帧来核对——这是标注类
  benchmark 做不到的。
- 陪衬:"以你现在的朝向,台灯在沙发的哪边?"所有东西当场可见,
  纯读图,做垫底基线:连这个都错的模型,深档的错不能归因到换算。

**成题条件。** 门、床、目标三者都清楚看到过;指称唯一;想象视点与
实际视点的夹角落在设定档位;答案离扇区边界有裕度。

**变体。** 打乱帧序→不变(证据是静态的);删掉门或目标的目击帧→
弃答;删冗余→不变;停顿→不变;**换视点→协变**——同一条录像,把
"站在门口"换成"站在窗边",金标按几何跟着变,由编译器重算。这是
新的一类手术:动的不是帧序列,是题面参数。角度—误差曲线从这里来。

**要建的东西。** 环视拍法(比走路拍法简单);想象位姿的答案算法;
题面参数手术这一类新算子;想象夹角的分档。

**待定。** 参照物怎么选(离目标太近夹角没意义,太远指称易含糊);
浅档要不要真渲染核对还是几何判断即可。

## 2. 对应锚定(基元B)

**拍什么。** 场景里摆两把一模一样的椅子(同款同色),录像先后路过
两把,各自看清。外观提供零判别信息,分清"哪把是哪把"只能靠
时空连续性——这是设计要点,不是缺陷。

**问什么。**

- "这段行走里你一共看到几把这种椅子?"金标:掩码里的实例数;每个
  被计数的实例必须清楚露过脸,有似露非露的就不出题。
- "现在画面里这把,是不是你先前在窗边看到的那把?"金标:实例 id
  直接给出是/否。

**指称问题。** 类别名("那把椅子")在这里天生有歧义,题面必须换
指称方式:按目击历史("你先看到的那把")或按区域("窗边那把")。
泄漏审计要配套改:区域定语不能恰好泄漏答案。

**变体。** 打乱→计数不变;删掉其中一把的全部目击帧→**计数协变**
(金标从 2 变 1,由重编译产生——注意这里删目击不是弃答,是答案
合法地变化,和其他剧本不同);删冗余→不变。

**要建的东西(卡脖子在前置)。** OminiGibson 侧的场景编辑:往现有
场景里放同款双实例。这是模拟器侧的活,建议尽早单独立任务书,
与 EpiSpace 侧并行。EpiSpace 侧:计数答案算法、历史/区域指称、
配套审计。

**待定。** 双实例摆放的最小间距和"各自靠近可辨识地标"要不要强制;
实例数先做 2 还是直接支持 2/3。

## 3. 跨视图绑定(组合二)

**拍什么。** 两件目标物 A、B **从头到尾没有同框过**(新条款,从
掩码验证),但各自和一个地标 L 同框过。想知道 A 和 B 的关系,只能
把"A 在 L 旁边"和"L 在 B 旁边"两段见闻拼起来。

**问什么。**

- 主打:"以你现在的位置朝向,电视在冰箱的哪边?"金标:两物世界
  坐标 × 当前位姿 → 相对关系;
- 副题:"电视和冰箱哪个离门更近?"金标:距离比,差距够大才成题。

**变体。** 打乱→不变(拼合不依赖顺序);删掉地标 L 的目击帧→弃答
(接力链断了);删掉 A 的目击帧→弃答;删冗余→不变;换锚链长度
(A–L–B 换成 A–L1–L2–B)→协变,链长曲线量"关系复合"的代价。

**要建的东西。** "永不同框"和"与地标同框"两条新条款;能搜出这种
走法的拍法——预计拒绝率高,是这个剧本的主要工程风险;链长分档。

**待定。** 关系的参照系用"你现在的朝向"还是房间固有方向;
地标由生成器选还是人工指定白名单。

## 4. 存在题(元能力主打)

**拍什么。** 不需要专属拍法,骑在任何录像上。核心是给每条录像算一个
**覆盖率**:视锥扫过的区域占全屋可走区域的比例。

**问什么。** "这个房间里有没有床?"金标三分:

- 床存在且清楚看到过 → "有";
- 床不存在,且覆盖率 ≥ 阈值(看遍了)→ "没有";
- 覆盖率不够、又没看到 → "无法判断"。

第三条是重点:没看遍就断言"没有",是把"没证据"当成了"证据表明没有"。
这个金标是构造出来的,市面基准没有。配套一个校准压力位:问先验很强
的物体(卧室问床)vs 先验弱的(卧室问烤箱),看模型是不是在凭常识
抢答而不是凭证据。

**变体。** 删掉目标的目击帧(若看到过)→金标变"无法判断"(不是
"没有"!);删掉覆盖某区域的关键帧→"无法判断";打乱→不变。

**要建的东西。** 覆盖率计算(位姿+视锥+遮挡,几何活);覆盖率阈值
进 standards;"没有"类题需要挑场景(问一个确实不存在的类别)。

**待定。** 覆盖率阈值定多少;先验冲突场景怎么系统地选。

## 5. 推进主线:先把 loop 跑起来

原则:**不攒大招**。不等五个剧本齐活,先用手里已有的题把
"出题 → 模型作答 → 家族级指标 → 结论"整条环路打通,之后每完成
一个剧本就回到环路里出一次数。理由:环路暴露的问题(指标定义、
作答格式、题面呈现)改起来,三条录像时是小事,三百条时是返工。

**M0 闭环(最优先,约一周)。**
评测指标模块:输入作答记录+题目包,输出条件一致率、弃答校准、
协变曲线,按题的角色(主打/探针/质检)和标签分组。两个假模型
(全蒙的、抄金标的)验证指标两端;再接一个真模型跑现有 12 个家族
(4 题 × 3 条录像),拿到第一张实测签名表。数据薄没关系,
要的是环路通。

**M1 自运动簇补全 + 批量渲染。**
按《自运动与路径积分》文档 §6 的顺序:偏科修复 → 纯旋转/纯平移/
多段转向 → 遮挡子型 → 配合模拟器侧碰撞复查批量渲染。做完回 M0
环路重跑,角度曲线和旋转/平移分离第一次有统计量。

**M2 参考系变换上线(本文 §1)。**
两个组合共享的"换算"引擎从此可单独测量,迁移实验的两翼齐了。
回环路重跑。

**M3 存在题上线(本文 §4)。** 校准从"变体副产品"升级为有主打题。

**M4 跨视图绑定(本文 §3)。** 链长曲线。

**M5 对应锚定(本文 §2)。** 依赖场景编辑,其 OminiGibson 侧任务书
在 M1 期间就发出去,两边并行,M5 只做 EpiSpace 侧收尾。

每个里程碑的完成定义都一样:新剧本的家族进环路、指标表更新、
设计文档的"待定"项清零或转正式决策记录。
