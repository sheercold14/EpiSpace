# QA 编排格式与泄漏控制 v1

> 状态：数据构造原则；与《轨迹分类与建图训练_v1》《multi-turn-generation》《训练流程_v1》正交互补——
> 轨迹分类回答"给模型看哪些视图"，建图训练回答"答案里外化什么"，本篇回答"问题在序列里怎么排布"。
> 三者组合成完整的模拟器数据构造原则，服务同一个目标：让模型获得**隐式空间理解能力**
> （内部维护场景状态的通用程序），而不是拟合某一种题面格式。

## 1. 第一性原理：一条训练序列的信息结构，决定它强化哪条回路

Teacher forcing 下，位置 t 的监督目标可以利用 t 之前上下文里的一切。多轮空间对话的
上下文里有三种信息源：图像、问题文本、**先前问题的 GT 回答**。由此产生两类泄漏：

- **L1 答案笔记本泄漏**：上下文中的历史 GT 回答构成一个"永远正确的笔记本"。
  若后题答案可以从前题回答的文本推出（"烤箱在冰箱左侧1.7米"→布局总结题），
  模型走语言复推，视觉/几何回路休眠。
- **L2 问题预告泄漏**：穿插式提问让模型**带着考点去看后续图像**
  （question-primed perception）。这violates query-agnostic write——
  观察被"未来的问题"过滤了，与"为题建图"是同一个捷径的时序变体。

两点辩证：L1 不全是坏事——结论复用即缓存，人也这么干；坏的是（a）训练时笔记本
永远正确、推理时笔记本是模型自己可能出错的历史回答（exposure bias 的对话版），
（b）若**所有**监督都带笔记本，纯视觉计算回路从未被单独施压。L2 则几乎全是坏事，
只在"边看边答"的具身流式场景里才是合法能力。

## 2. 四种编排格式：互补组合，不是单选

| 格式 | 结构 | 独占训练价值 | 泄漏风险 | 对应真实场景 |
|---|---|---|---|---|
| **A 穿插式** | 图-问-答-图-问-答…（现状） | 增量状态维护、记忆回溯、状态修正（delayed reveal） | L1+L2 都有 | 具身流式交互 |
| **B 先看后问** | 全部图像→全部问题→依次作答 | **最纯净的 write/read 分离**：观察时问题不存在，L2 物理消灭；K 道多能力题同时压到，状态不完整必错→**完整建图压力最大** | 批内 L1（答案间互看） | VSI/MMSI 考试形态的摊销版 |
| **C 单题式** | 全部图像→单题单答 | 与 benchmark 测试格式对齐；等预算 A/B 实验的基线格式 | 无（也无复用压力） | 考试本身 |
| **D 先建态后问** | 图像→输出完整地图（COMMIT）→（可选撤图）只凭已输出状态答题 | 显式 read-from-state；state sufficiency 的训练版 | 无 L2；state 即公开笔记本（设计使然） | 契约 §3 的直接实现 |

**B 是对现状的关键补充**（正是本次讨论的动因）：现有 episodic_dialogue 全是 A 格式，
穿插的问题确实在"预告"后续观察的考点——A 格式在训记忆的同时不知不觉违背了
query-agnostic write。B 格式把它修回来，且不需要新渲染：同一 bundle 换编排即可。

**推荐配比**（episodic 数据内部）：A 40% / B 35% / C 15% / D 10%。
理由：A 保记忆与增量修正（其他格式给不了）；B 保纯净建图压力；C 保考试格式与
对照可比性；D 保显式状态接口（也是 structured_aux 的宿主）。

## 3. 泄漏的机检（构造时执行，不等评测时发现）

1. **文本探针**（对 A、B 批内）：去掉全部图像，只喂截至第 k 轮的对话文本，
   用一个小 LLM 预测第 k 题答案。可预测 → L1 泄漏，重排问题或降低前题答案的信息量。
   这是把 SenseNova 的 vision-free 诊断从评测搬到构造时。
2. **依赖筛查**（对 B 批内、A 轮间）：certificate 字段级判定——后题的证据闭包
   不得是前题答案信息量的子集（同一 relation 的同一实体对不重复出现在可互推的两题）。
3. **预告审计**（对 A）：题目涉及实体若主要出现在**提问之后**的图像里 → 考点预告，重排。
   （合法例外：delayed reveal 的"先弃答后修正"——那是刻意考状态更新。）
4. **笔记本防信**（小比例，~5%）：按契约 §7.3 的 corrupted-trace 协议，
   在 A 格式中植入带单因素错误的早轮回答，后轮显式要求复核并修正。
   训练"不盲信上下文"，对冲 exposure bias。

## 4. 从第一性原理总结：隐式空间能力 = 三个正交压力的交集

模型内部长出"通用建图程序 + 按题激活的最小读取回路"，需要且只需要三种训练压力同时存在：

1. **保留压力**（B/D 格式 + 多题摊销）：观察时不知道会被问什么，问题又多又杂
   → 内部状态必须完整（write 相 query-agnostic）；
2. **读取压力**（最小充分子图 trace + token 成本）：答题时只externalize相关子图
   → 读取回路按题伸缩（read 相 query-conditioned）；
3. **一致性压力**（family 变体 + 干预对 + 图-答执行器）：答案必须随证据变化
   → 捷径全部死路。

三者缺一：只有1→会建图不会用；只有2→为题建图；只有3→靠对抗样本打补丁没有正向机制。
