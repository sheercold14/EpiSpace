# ICLR 2027 核心主线与数据管线 v1

> 工作标题：**EpiSpace: Counterfactual Episode Families for Systematic Spatial Composition**  
> 冻结范围：本文记录当前代码、采集资产和独立审计能够证明的事实；在 B-vs-C 训练完成前，不声称模型能力提升、外部迁移或 SOTA。  
> 一句话贡献：在 RGB、事实与视觉计算可配平的条件下，用**反事实 episode family + 原子已见/程序签名未见的组合测试**，检验 observe-first、read-many 训练是否比孤立 QA 更容易学到可复用空间计算。

## 1. 为什么这是值得投稿的问题

孤立样本 `(O, q, y)` 的答案损失无法区分两条电路：

```text
可复用电路：O1:M → query-agnostic belief S → 按 q 执行空间 read → y
捷径电路：  (O, q) 的局部线索 / 模板 / 标签先验 → y
```

两者答对都得同样梯度；文本 CoT 也不能证明中间陈述正确或被因果使用。SenseNova-SI 已表明大规模覆盖可以提高能力，但也暴露语言捷径、鲁棒性和文本推理收益不稳定。与此同时，SPRITE 已占据 simulator→executable QA，S3-Bench/AMF-VLM 已覆盖 streaming trajectory，SpaMEM/EMemBench 已覆盖空间记忆，Cog3DMap/OmniView-Space/S-Agent 已覆盖显式地图或工具。因此我们不能再声称“首个模拟器 QA、轨迹数据、空间程序、地图或 memory”。

可辩护的空位是四项控制的**联合**：

1. 一个 latent fact 对应完整 sibling family，而不是互不相干的 QA；
2. train 看过 `G/F/B/M/R/P/V` 全部原子，但未看过指定完整程序签名；
3. isolated 与 observe-first 使用同一事实，并提供事实配平和图像计算配平两套制度；
4. consistency 必须以 atomic accuracy 为条件，防止“始终猜同一个答案”或“始终弃答”得高分。

## 2. 第一性原理数据契约

### 2.1 coverage-first：轨迹先于问题

轨迹是在 `SE(3) × time` 上控制视差、重叠、遮挡、揭示和参照系的实验变量。采集时不知道下游问题；QA 在轨迹冻结后由真值程序生成。否则视点本身会泄漏考点，模型学到“为题找图”，而不是先建立可复用表示。

### 2.2 observe-first：write 与 read 解耦

主训练记录先给完有序 RGB，再批量给最多 6 个异构问题。一个观察前缀同时服务 grounding、memory、metric、relation、perspective、verification 等 read。主模型只看到 RGB、相机高度/FOV 和自然语言；pose、depth、mask、实体 ID、typed program、certificate 与 target render 都是隐藏通道。

### 2.3 observable canonical belief，不是 simulator 全知图

辅助 state 以第一帧相机地面投影为原点，`+X=相机右`、`+Y=水平前`、`+Z=重力上`；只包含至少被一个输入视角观察到的实体，位置/尺寸按 0.5 m 量化，并记录 first/last evidence 与 `visible/seen_not_current`。从未观察的 world entity 禁止进入 state。State 是独立请求的 auxiliary target，不是普通 QA 的提示。

### 2.4 typed program 是后台 IR，不是学生输出格式

每题映射为 answer-free DAG：`Grounding(G)`、`Frame(F)`、`Belief(B)`、`Metric(M)`、`Relation(R)`、`Perspective(P)`、`Verify(V)`。节点显式声明输入/输出类型；类型错误即拒收。主模型无需生成 DAG 或 UUID。IR 只承担：轨迹合法性、程序组合留出、certificate 路由和错误定位。

### 2.5 geometry-first、language-last

生产顺序固定为：

```text
实体绑定 → 实际输入视角 → frame → 连续几何量/margin
→ structured target → 独立 replay certificate
→ 中文问题与回答 surface
```

语言 realization 不能同时读取可自由发挥的 question slot 和 answer slot。当前 pilot 使用确定性中文模板；未来若用 Claude/VLM 改写，只允许读取 question-side fact，并在改写后重新解析、重放和做功能依赖检查。

## 3. 论文真正的三个 contribution

### C1. Counterfactual Spatial Episode Families

当前冻结版实际 materialize 133 组 family：

| Family | 数量 | 固定内容 | 干预与义务 |
|---|---:|---|---|
| evidence triple | 91 | 同场景、同问题、同图数、共享图及其槽位 | `unknown → known → unknown`；只替换一个决定图 |
| claim pair | 37 | 同一跨视图真实关系与视觉输入 | 假命题与真命题平衡；两者都要答对 |
| frame pair | 5 | 完全相同的两张 RGB 与实体对 | 仅改变哪台相机定义“前方”；方向必须随 frame 等变 |

91 个 evidence triple 由 85 个通用 presence family、5 个 never-co-visible cross-view family 和 1 个 T8 reveal family 构成。Cross-view triple 固定两个图像槽，只替换第三张；presence triple 固定一个槽，只替换另一张。Family 缺成员、图数不等、共享图换槽、问题文本不同或 split 不同均阻断 release。

### C2. Fail-closed Geometry-to-Episode Compiler

```text
322-job sweep ledger
→ 只读取 plan_status=passed 的 bundle
→ raw RGB channel extraction（禁止 RGB/depth/instance preview）
→ trajectory legality + referent unique + ≥500 instance pixels
→ observable belief + typed program
→ balanced contrast / sibling interventions
→ independent geometry replay
→ episode / isolated / state / RLVR / benchmark exports
→ 18 corpus gates + rejection ledger
```

关键 gates：scene/family lock、完整 family shape、相同输入只能有一个 structured target、program typing、holdout 原子覆盖、RGB purity、T10 path/hash 双重隔离、全 certificate check 为真、全 target 独立重放。当前 `1093/1093` replay 通过，所有 corpus gates 为 `pass`。

### C3. Controlled Episode-Learning Protocol

同一批 651 个事实导出两臂：

- **fact-matched**：340 条 episode、651 条 isolated；事实权重逐项相同。Episode 只出现 1,168 次图像，isolated 为 3,227 次，体现 63.81% 的观察摊销，但这不是 compute-matched。
- **image-occurrence-matched**：episode 按每条包含的事实数 `k` 重复 `k` 次并赋 `1/k` loss weight；两臂均 651 draws、3,227 次图像、3,383,754,752 input pixels，有效事实权重仍逐项为 1。

精确 Qwen3-VL tokenizer（256²）进一步确认：两臂 image tokens 均为 206,528，但
episode/isolated 总 input tokens 为 415,424/362,185（episode +14.70%），text tokens
为 208,896/155,657。因此本版本只能称 **visual-exposure-matched**，不能笼统称
compute/FLOP-matched。训练 loss 必须是“每事实 answer span 内 mean CE → record 内求和
→ 乘 `sample_weight`”，不能用整段 assistant token mean。

主因果问题只比较 B（observe-first）与 C（isolated）。Observable-state D 和 RLVR 是后续独立消融，不能和主方法捆绑后把收益归因于 episode。

## 6. 主评测：不能只看 accuracy 或 consistency

必须同时报告：

1. atomic structured accuracy（task/program/split 分解）；
2. family exact match；
3. claim-pair exact；
4. frame-pair equivariance exact；
5. revealed accuracy；
6. accuracy-conditioned evidence sensitivity：

\[
ES_{correct}=
\frac{\sum_f c_{f,reveal}c_{f,prefix}c_{f,delete}}
     {\sum_f c_{f,reveal}}.
\]

分母为 0 时记 N/A，不能记 1。始终弃答会使 reveal 错，始终猜具体方向会使两个 unknown 错。置信区间按 scene/family cluster bootstrap，而不是把每条 QA 当独立样本。

当前只完成 oracle smoke（用于证明 evaluator 接线正确），没有模型 prediction，因此数据审计中的模型指标必须标为 `not_evaluated`。

## 7. 与 2026 同类工作的边界

- SPRITE：已证明 simulator + executable program 可以规模化生成空间 QA；我们不争“程序化生成”。
- S3-Bench/AMF-VLM、SpaMEM、EMemBench：已覆盖 trajectory、streaming memory、动态 belief；我们不争“首个 episodic/streaming benchmark”。
- Cog3DMap、OmniView-Space、S-Agent：已覆盖 explicit map、query-aligned reconstruction 和工具代理；我们的学生推理时没有外挂几何工具，canonical belief 仅是可选监督。
- ReVSI：强调 exact-frame answerability；我们的 certificate 必须针对实际 RGB 输入重放。
- ViewDiag：说明一致但错误仍可能几何失真；因此我们使用 atomic-accuracy-conditioned family metric。

论文 novelty 必须始终表述为：**counterfactual sibling family × signature holdout × paired compute-accounted training × accuracy-conditioned evidence sensitivity**。任意单项都不是首创。

## 8. 可证伪实验与不允许提前写的结论

主实验：相同 8B MLLM 初始化、相同 optimizer/steps/general-data replay，在 image-occurrence-matched schedule 上比较 B vs C；三随机种子，scene-cluster bootstrap。主终点是两个 held-out signature 的 scene-disjoint accuracy；并列诊断是 family exact 与 `ES_correct`。

以下结论必须等真实训练后才能写：

- episode 提升组合或场景泛化；
- canonical state 被模型内化或因果使用；
- RLVR/GRPO 有效；
- transfer 到 MindCube/MMSI/VSI/ViewSpatial；
- 通用能力无损或达到 SOTA。

若等计算 B-vs-C 没有提升，机制假设被否证；仍可将本文作为数据引擎与控制 benchmark 报告，但不能把数据结构本身当成学习收益。
