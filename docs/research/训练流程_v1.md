# MLLM 空间后训练流程 v1

> 状态：训练流程规范；配套数据由 `scripts/build_training_samples.py` 从模拟器 bundle 编译。
> 目标：空间推理能力增强、场景可泛化，同时通用 QA / 对话能力不退化，不过拟合单一程序格式。
> 第一性原理：结构留在数据引擎（出题+验证+奖励），模型接口层是自然语言；SFT 注入行为分布，RLVR 提纯正确性。

## 0. 样本层设计（与编译器一一对应）

| 类型 | 形态 | 配比（按图像 token 曝光） | 作用 |
|---|---|---|---|
| `episodic_dialogue` | 图像按轨迹顺序逐张进入多轮对话；穿插即时观察 / 记忆回溯 / 跨视图整合 / 弃答与揭示后修正；state 隐式存在于上下文 | 20% | 场景状态维护的 MLLM-native 训练 |
| `grounded_cot` | 单/多图 QA + 从几何编译的自然语言推理，每个数值与方向经 certificate 复算 | 15% | 可验证的空间推理链（替代不可验证的文本 CoT） |
| `direct_qa` | 短答案，方向 / 距离 / 可见性 / 共现 / 未观察即弃答；答案方向分布强制均衡 | 10% | 保持直接作答行为，防 CoT 冗长化 |
| `spatial_caption` | 布局总结与区域描述；目标文本只含实际被观察实体 | 5% | 格式自由的状态表达（自然语言 state commit） |
| `structured_aux` | 指令显式要求时输出 JSON belief state（`format_conditioned=true`） | 5% | 表征塑形；格式是应指令的技能而非默认行为 |
| 通用回放 | SenseNova raw QA + 通用多模态（对话 / OCR / 描述） | 45% | 防遗忘的生命线 |
| `rlvr` | 仅 prompt + 机器可判的 reward_spec，无参考回答 | 不入 SFT | 阶段二 RL 专用 |

所有样本共享同一 `family_id` 与 `split_lock`：episode family 的全部 variants（canonical / delayed_kitchen_reveal / decisive_views_deleted）只能进入同一个 split，杜绝扰动泄漏。

## 1. 阶段一：混合 SFT

- **基座**：`sensenova/SenseNova-SI-1.1-InternVL3-8B`（已具备空间先验，做增量对照最干净）；对照组用原始 InternVL3-8B 验证结论不依赖基座。
- **混合**：按上表配比在样本级混池，单阶段训练。不要做"先模拟器后通用"的顺序训练——顺序训练几乎必然灾难性遗忘。
- **超参**（8B 全参）：LR 1e-5（ViT 侧 2e-6 或冻结），cosine decay，warmup 3%，1–2 epoch，全局 batch 128–256，图像分辨率沿用基座 dynamic tiling。
- **Loss 规则**：只对 assistant turns 计 CE（多轮对话的每个 gpt turn 都计）；`loss_policy.train_on` 字段直接驱动 collator。
- **采样规则**：同一 episode 的多条样本高度相关——每个 epoch 每 episode 至多采 4–8 条；family-aware 采样保证同族 variants 不进同一 batch（一致性由数据保证，不需要成对 loss）。
- **守门评测**：每 500–1000 步跑 MMBench-En 子集 + 通用 VQA 子集 + VSI-Bench 子集。通用能力掉幅 >1–2pp → 停止并调高通用回放比例或调低 LR，不要继续训。

## 2. 阶段二：RLVR（模拟器数据的独有优势）

- **算法**：GRPO / RLOO 均可；每 prompt 采样 8–16 条自由格式回答。
- **奖励**：由 `meta.reward_spec` 机器判分——
  - `enum`：答案文本归一化后命中 correct 方向/象限记 1；
  - `numeric`：解析出的数值落入 `correct ± tolerance` 记 1；
  - `boolean`：能/不能判断正确记 1；
  - `abstain`：明确表达"无法确定/证据不足"记 1，给出任何具体方向记 0（反向惩罚幻觉自信）。
- **一致性奖励**：`consistency_group` 内成对采样（如 tv_fridge_direction 的完整证据版与删证据版），完整版答对且删减版正确弃答额外 +0.5；一个答方向一个也答方向（矛盾）记 0。
- **KL 约束**：对 SFT checkpoint 加 KL 惩罚（β≈0.01–0.05），防止奖励黑客化与语言风格漂移。
- **低成本替代**：拒绝采样自蒸馏——SFT 模型每 prompt 采 8–16 条，certificate 过滤出答案正确的自然语言回答，混回 SFT 池再训一轮。效果打折但无 RL 基建要求。

## 3. 评测与预注册门槛（沿用研究契约 v1）

- **主指标**：scene-disjoint held-out graph-signature accuracy，相对 isolated-QA 等预算基线 ≥ +5pp。
- **共同主指标**：episode-family all-member consistency ≥ +10pp。
- **守门**：通用 QA（MMBench 等）掉幅 ≤1pp。
- **捷径诊断**（直接复用 SenseNova-SI 论文的工具，形成对外可比证据）：vision-free 掉幅应显著（证明视觉接地）、circular test 掉幅小（证明无选项捷径）、删证据变体弃答率高（证明认知诚实）。
- **A/B 纪律**：isolated-QA 与 episode 两种 exporter 使用相同问题事实、相同图像出现多重集/像素/视觉 token，并以 `comparison_id` 为单位对齐 Adam 更新数。文本 token 和 FLOP 必须单独报告，不得宣称已配平；统计单位是 scene/episode family，三种子 + scene-cluster bootstrap 95% CI。

## 4. 规模化路径

当前产物是单场景 development exemplar（Rs_int_seed17，仅验证格式与管线）。正式训练最低门槛：

1. ≥30 个 scene-disjoint 场景（pilot）→ 通过预注册门槛后扩至 ≥150 场景；
2. 扩展预算优先花在场景几何多样性（布局拓扑 / 尺度 / 遮挡密度），而非同场景复制题目；
3. 问题文本经 LLM 批量改写（`paraphrase_pool=true` 的样本），改写后重新校验答案分布均衡；
4. 跨后端轴：OmniGibson 训 → HM3D 真实扫描测（或反向），作为场景泛化的强证据；
5. SenseNova bridge：按 exact-image-tuple 把真实图像域接入 episode 结构，防 sim-to-real 断裂。

## 5. 已知风险与对应信号

| 风险 | 信号 | 处理 |
|---|---|---|
| 格式过拟合 | 普通问题冒出 JSON / 固定推理套话 | 降低 structured_aux 与 CoT 比例；检查 format_conditioned 隔离 |
| 通用能力退化 | 守门评测掉 >1–2pp | 提高通用回放比例、降 LR、缩 epoch |
| 场景记忆 | scene-disjoint 与 IID 差距拉大 | 增加场景数而非题量 |
| 弃答过度泛化 | 可答题也说无法确定 | 保持 unknown 占比 ~15%，弃答样本必须与可答样本同族出现 |
| 奖励黑客 | RL 后答案短语化 / 模板化 | KL 约束 + 人工抽检 + 语言质量守门 |
